# Changelog

Each section is one firmware version. When the number in the `VERSION` file changes on `main`, GitHub publishes a release automatically. The section for that version becomes the release notes.

## 2.0.0

- First release with a ready-to-use `.uf2` file. GitHub builds the file automatically.
- Four instruments: Dub Siren, Ray Gun, Lead Synth and Disco.
- Special functions: sequencer, recorder, reverse, infinite delay, LFO 2, drone and sidechain.
- Mutate on the sync input.
